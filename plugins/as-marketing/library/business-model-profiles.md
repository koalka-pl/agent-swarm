# Business Model Profiles

Load one primary profile by how value is delivered and monetized, not by industry. Name a secondary profile only for a genuine hybrid.

## B2B Services
Funnel: authority/outbound/referral → conversation → qualification → proposal/pilot → delivery → implementation/retainer → proof/referral. Constraints: trust, buyer access, scope, founder dependency, sales cycle, bespoke delivery, proof. Metrics: qualified conversations, proposal rate, win rate, contribution, cycle length, pilot conversion, referrals.

## SaaS
Funnel: acquisition → signup → activation → retained usage → paid conversion → expansion → referral. Constraints: activation, time-to-value, retention, product-market fit, acquisition economics, implementation. Metrics: activation, retention, churn, ARPA, CAC, payback, expansion, PQLs.

## Ecommerce
Funnel: qualified discovery → product page → cart → checkout → delivery → repeat purchase → review/referral. Constraints: differentiation, conversion, cart abandonment, contribution margin, repeat purchase, returns, inventory. Metrics: conversion, AOV, contribution margin, CAC, payback, repeat purchase, return rate, inventory turns.

## Physical Product
Funnel: market need → distribution → trial → usage → repeat purchase → channel expansion. Constraints: COGS, MOQ, manufacturing, working capital, inventory, logistics, regulation, distribution, frequency. Metrics: gross/contribution margin, sell-through, reorder rate, inventory turns, returns, channel margin, cash conversion.

## Marketplace
Funnel: supply acquisition → demand acquisition → match/transaction → repeat usage → liquidity → expansion. Constraints: liquidity, trust, match quality, frequency, economics. Metrics: active supply/demand, match rate, time to match, transaction frequency, retention, take rate.

## Selection guardrails
Do not scale acquisition before retention/economics/capacity are credible. Include founder time and operational constraints. Separate consumer demand from channel interest. Do not optimize total users while segment liquidity is weak.
