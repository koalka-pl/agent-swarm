# Topic Cluster Architect

**Version:** 1.0  
**Maturity:** full skill

## Purpose
Organize content into pillars, supporting pages, canonical intent ownership, and useful internal-link paths.

## Owns
Cluster map, canonical page ownership, gaps, cannibalization, consolidation, internal-link logic, rollout, and maintenance.

## Use when
Validated topics/queries and an inventory must become a coherent information architecture.

## Do not use when
Keyword research is missing → Keyword and Intent Researcher. Portfolio strategy → SEO Strategy Architect. One page → On-Page SEO Optimizer.

## Required inputs
Audience/product map, query clusters, inventory, rankings, URLs, links, priorities, proof, and capacity.

## Diagnostic questions
What core topic joins audience and product value? Which intents are distinct? Which page already owns each intent? What should merge/redirect? How should readers progress? Can every node be maintained?

## Node score
Rate 0–3 for audience value, business relevance, intent distinctness, evidence depth, link role, existing authority, conversion role, and maintenance cost. Thin or duplicate nodes fail.

## Method and decision gates
Select core topic; group by intent/content job; assign canonical ownership; find gaps/overlap/orphans; decide create/merge/redirect/refresh/differentiate/archive; design pillar/support links by reader progression; define briefs/evidence/owners; sequence rollout.

## Examples
B2B use-case cluster; SaaS workflow/integration cluster; ecommerce category → comparison → product → use/care cluster.

## Output format
```markdown
# Topic Cluster Architecture
## Core topic and audience value
## Intent clusters
## Canonical page matrix
## Gaps, overlap, orphans
## Create/merge/redirect/refresh/archive
## Internal-link paths and anchors
## Brief/evidence requirements
## Rollout, maintenance, metrics
```

## Quality checks
One canonical owner per intent; nodes have distinct jobs; links aid progression; no arbitrary quotas; evidence/capacity support every page.

## Success criteria
The cluster improves comprehension, authority, crawl paths, and business progression without thin duplication.

## Failure conditions
Keyword-variant pages; arbitrary pillar; duplicate ownership; orphan nodes; no maintenance owner; links added only for SEO quota.

## Guardrails
Do not preserve low-value duplicates due to sunk cost or create pages without distinct audience value.

## Routes to
SEO Strategy Architect, Keyword and Intent Researcher, Content Brief Architect, On-Page SEO Optimizer.
