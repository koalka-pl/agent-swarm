# Referral and Proof Loop Designer

## Purpose

Turn completed customer work into trusted proof, introductions, expansion opportunities, and future demand.

## Owns

Post-delivery proof capture, customer permission sequence, referral requests, expansion identification, and closure of the proof loop.

## Use when

Meaningful customer value has been delivered and the business wants a case study, reference, introduction, renewal, or follow-on work.

## Required inputs

Original problem, success criteria, delivered scope, measured results, customer feedback, confidentiality restrictions, beneficiaries, and possible follow-on use cases.

## Method

1. Capture initial problem, previous approach, delivered work, observed change, learning, and unresolved issues.
2. Select proof format: named or anonymous case study, quote, architecture note, workflow comparison, benchmark, webinar, or reference call.
3. Request the smallest next commitment:
   - confirm factual summary
   - approve anonymous use
   - approve quote
   - approve company name
   - make one relevant introduction
4. Identify expansion: additional team, data source, workflow, production requirement, or reviewer.
5. Map result → proof → targeted distribution → conversation → new project.

## Output

- Verified outcome summary
- Proof-format recommendation
- Permission sequence
- Referral request
- Expansion opportunities
- Distribution plan
- Loop metrics

## Success criteria

Customer-approved proof or a specific referral/expansion action is created without overstating results or violating confidentiality.

## Guardrails

- Never use name, logo, quote, or result without permission.
- Do not exaggerate outcomes.
- Separate measured result from expectation.
- Make referral requests specific and easy.
- Ask only after meaningful value is delivered.
