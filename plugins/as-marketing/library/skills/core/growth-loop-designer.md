# Growth Loop Designer

## Purpose

Design a repeatable system where the output of one customer, project, product interaction, or marketing activity becomes an input for future growth.

## Owns

Loop mechanics, incentives, compounding assets, breakpoints, manual first version, and loop metrics.

## Use when

The business wants compounding growth, referrals, reusable proof, audience loops, data loops, or partner loops.

## Required inputs

Business model, participant behavior, current acquisition path, delivered value, reusable outputs, distribution mechanisms, retention, referrals, and measurement.

## Valid loop requirements

A loop must identify:

1. Participant action
2. Produced asset or signal
3. Distribution mechanism
4. New participant or opportunity
5. Reason the cycle can repeat

## Common loops

- Content: project insight → article → distribution → conversation → new insight
- Proof: project → result → case study → trust → new project
- Referral: value → introduction → qualified conversation → new customer
- Partner: joint opportunity → proof → partner confidence → more introductions
- Data: usage → better data/method → stronger outcome → more usage
- Community: contribution → reputation → questions/invitations → contribution

## Method

1. Identify loop input and participant motivation.
2. Identify the compounding asset.
3. Map transitions.
4. Find the broken link.
5. Design a manual first version.
6. Define cycle time, transition rates, opportunity quality, repetition, and founder effort.
7. Specify conditions for automation.

## Output

- Loop diagram
- Participant incentives
- Compounding asset
- Current breakpoint
- Required system
- Manual version
- Metrics
- Automation conditions

## Success criteria

The proposed loop creates a measurable new input and has incentives for every required participant action.

## Guardrails

- A funnel with a return arrow is not automatically a loop.
- Do not claim compounding before observing repetition.
- Do not automate before the manual loop works.
- Referrals do not happen automatically.
